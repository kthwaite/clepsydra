# UI Guidance (ui/)

Loaded when working under `ui/`. Root-level rules (verification gates, feature workflow, git workflow) still apply.

## Frontend Stack

- **React 19** with TanStack Router (file-based routes in `ui/src/routes/`) and TanStack Query
- **Zustand** stores in `ui/src/store/` — workspace tabs, quires (tab groups), board, UI prefs
- **Vite 8** — standard Vite (the previous `rolldown-vite` override has been removed)
- **Tailwind CSS v4** — All design tokens live in `ui/src/main.css` via `@theme` blocks. No `tailwind.config` file.
- **Biome** for linting and formatting (replaces ESLint/Prettier). Config in `ui/biome.json`.
- **react-aria-components** for accessible UI primitives
- **Storybook 10** for component development (`ui/.storybook/`)
- Central keyboard-shortcut registry: `ui/src/lib/shortcuts.ts` + `useGlobalShortcuts` dispatcher

**Path alias:** `#/` maps to `ui/src/` (configured in both `tsconfig.app.json` and `vite.config.ts`). Use `import { Foo } from "#/components/Foo"` not relative paths.

**Auto-generated files (do not edit):**
- `ui/src/routeTree.gen.ts` — Generated by TanStack Router plugin
- `ui/src/api/schema.d.ts` — Generated by `bun run openapi`

## Editor (ui/src/editor/)

Slate.js editor with a registry-driven schema. Plugin chain: `withReact(withHistory(withAutoformat(withOutliner(withSchema(createEditor())))))`.

- Element types live one-per-file under `schema/elements/`; each descriptor owns kind/create/render/normalize/toMdast. `getDescriptor` + `REGISTRY` in `schema/registry.ts`; cross-node rules in `schema/documentRules.ts`. Adding a type = 1 elements file + 1 union line in `schema/types.ts` + 1 registry entry (+ 1 `mdast-to-slate` branch if it deserializes).
- Canonical list shape is `list-item > paragraph > text`; the list-item descriptor's normalize always claims the node, so all transforms must produce that shape.
- Markdown round-trip via mdast (`convert/`), autoformat + outliner + paste handling in `plugins/`, optional vim mode in `vim/`.

## Design Aesthetic

The UI is **Stone & Lamp** (spec: `docs/superpowers/specs/2026-09-25-stone-and-lamp-redesign-design.md`), which replaced Vessel. All six migration phases are done.

- Palette: bone (light, `.paper` on `<html>`, the **default**) and charcoal (dark, base `:root`); **cobalt** is the only accent (`#1747E6` bone / `#809CFF` charcoal). No accent presets.
- Every colour is a bare property on `:root`/`.paper`; the `@theme` `--color-*` tokens are `var()` aliases. The colours are `ground`, `raise`, `sink`, `ink`, `ink-2`, `mute`, `faint`, `rule`, `accent`, `accent-tint`, `warn`, `hot` and `scrim`, plus the `--quire-*` and `--code-*` properties. There are no Vessel (`paper`, `ink-mute`, `cool`, …) or shadcn (`background`, `muted`, `destructive`, …) names; a class using one renders no colour.
- Type: **Geist** (sans) for UI and prose, **Instrument Serif** (regular + italic only — never bold) as accent, **JetBrains Mono** for code only. Code gets mono from the `:where(pre, code, kbd, samp, [data-code-editor])` rule in `main.css`; don't add `font-mono` elsewhere.
- Radius 12px on surfaces, pills for buttons; soft shadows on overlays only. No new hairline borders — separate with space and tone.
- Settings writes `data-density` on `<html>`, but nothing reads it yet: spec §9 Q2 wants it to set the default of each table's Compact switch. The diegetic-chrome setting is gone.
- Primitives: `Section` (tick + italic serif eyebrow; replaces `Card`), `Tick` (`live`/`pulse`/`faint`), `Button` variants `primary` (cobalt pill) / `secondary` (the "quiet" sink button) / `ghost` / `danger`, `IconButton` (32px round ghost), and `FOCUS_RING` / `FOCUS_RING_NATIVE` (`lib/focusRing.ts`) on every interactive control. Style with `<Button>` and Tailwind tokens, not new global classes.
- Tables: `DataTable` (`components/ui/data-table/`, TanStack Table v9 + our own `role="grid"` keyboard model in `grid-navigation.ts`) renders Bases and the Gazetteer. It owns column widths, reorder (drag + Alt+Arrow), visibility, pinning, and checkbox selection; callers own the state and supply cells. Keep each cell's first focusable descendant its real control (no focusable wrappers), mark in-cell editors `data-grid-editor`, and mark controls grid navigation must skip `data-grid-skip`.
- Guards: `src/__tests__/primitivesGuard.test.ts` walks every `.ts`/`.tsx`/`.mdx` file under `src` (stories included, tests excluded) and fails on Vessel chrome: caps, tracking, mono, hard borders, 9–11px type, retired classes, Vessel/shadcn colour names and font aliases. Sanctioned exceptions go in its `ALLOW` map. `src/__tests__/deadCss.test.ts` fails when `main.css` defines a class no source file uses, sets caps, or uses mono outside code. A `<ul>`'s own padding utilities apply over the base-layer indent; hot text sits on raise/ground or at most `bg-hot/5`, never on sink.
- Shell: header = wordmark (home) + `CORE_NAV` + `ContentsMenu`; new screens get a `group`/`description` in `VIEW_REGISTRY` and appear in Contents, never in the header. The footer (`ShellFooter`) reads `useSaveStatus` and the `footerContext` store — a screen adds right-hand context with `useFooterContext(parts)`.

All semantic colour tokens live in `ui/src/main.css`; `ui/src/__tests__/themeTokens.test.ts` and `themeFonts.test.ts` pin them.

## Code Style (TypeScript/React)

- Biome handles formatting (2-space indent, double quotes, organized imports)
- Strict TypeScript (`noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax`)
- Use `clsx` and `tailwind-merge` for conditional class composition
