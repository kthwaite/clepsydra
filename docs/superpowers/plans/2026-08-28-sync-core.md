# Sync Core (phase 4a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make a vault a git repository that `clep` commits, fetches, merges, resolves and pushes on its own — `clep sync init`, `clep sync`, `clep sync status`, the server-side engine with quiesce, autocommit, startup pull and shutdown push, and doctor checks — never leaving the working tree conflicted.

**Architecture:** A new vault-level module `src/vault/gitsync/` wraps the system `git` binary via `std::process::Command` (`git.rs`), sets a repo up (`init.rs`), and runs the sync algorithm (`engine.rs`): commit local → fetch → merge `--no-commit` → resolve every unmerged path (ours stays, theirs becomes a Conflict Copy via `conflict_copy.rs`) → commit → push (one retry after a rejection). The server wraps the engine in a quiesce window (`src/sync_runtime.rs`: mutation gate held write, watcher paused, one full index rebuild + reconcile + SSE afterward) and drives autocommit/interval/startup/shutdown; `src/api/sync.rs` exposes it; the CLI calls the server when one answers and runs the engine standalone otherwise. This plan ships whole-file conflict resolution; the structural `*.md` merge driver, journal merger, and conflict surfacing (doctor rules + UI) are phase 4b.

**Tech Stack:** Rust 2024, `std::process::Command` (system git ≥ 2.30), `toml_edit` (config writer), `sha2` (conflict-copy short ids), `gethostname` (new dependency, Device trailer), Axum 0.8 + utoipa, tokio (`spawn_blocking`, `Notify`, `signal`), existing `MutationCoordinator::exclude_mutations`, `IndexHandle`.

**Spec:** `docs/superpowers/specs/2026-08-27-clep-sync-design.md` (§§2–6, 10), ADR 0004 (`docs/adr/0004-conflict-copies-over-merge-markers.md`), ADR 0005 (CAS migration inside init).

## Global Constraints

- Vault root = git repo root. `clep sync init` refuses when the vault root sits inside an outer repository (error names the outer top-level).
- Single remote `origin`, single branch (`[sync] branch`, default `"main"`). Never force-push. Never merge unrelated histories (git's default refusal is surfaced as an error; the merge is aborted).
- `.gitignore` managed lines (exact): `.clepsydra/cache.db*`, `.clepsydra/feeds.db*`, `.clepsydra/*.lock`, `.clepsydra/.feeds.db.*.lock`, `.clepsydra/transactions/`, `.clepsydra/cas/cas.db*`, `.clepsydra/cas/cas.lock`, `.clepsydra/crypto/*.identity.age`, `.DS_Store`.
- `.gitattributes` managed lines (exact): `*.md merge=clep`, `.clepsydra/cas/** filter=lfs diff=lfs merge=lfs -text`, `_attachments/** filter=lfs diff=lfs merge=lfs -text`.
- git-lfs is v1-mandatory: `clep sync init` hard-refuses without `git lfs`, and with `--remote` refuses unless the remote answers the LFS batch API. Tests inject `LfsPolicy::Skip`; the CLI never can.
- `[sync]` config keys and defaults: `autocommit_debounce_secs = 300`, `interval_secs = 0`, `branch = "main"`, `author_name`, `author_email` (strings, absent until init seeds them). It lives in `.clepsydra/config.toml`, which itself syncs.
- Commit messages are machine-generated: `sync: 3 pages (Title A, Title B, Title C)`; author from `[sync]`; every commit carries a `Device: <hostname>` trailer.
- Conflict Copies: `<stem>.conflict.<shortid>.md`, fresh page id, `conflict_of = "<original vault-relative path>"`, kind/tags (all other frontmatter) copied. The tree is never left conflicted after a sync.
- All git operations on the server run inside a quiesce window: watcher paused, mutation gate held write. Afterward: one full index build + link resolve, reconcile sweep, then SSE `index_changed` (`upserted: ["*"]`).
- Crypto file permissions re-tightened (dir 0700, files 0600) after every merge that touched the tree.
- The engine must never read the app-level config lookup (`~/.config/clepsydra/config.toml`) implicitly: it operates on the `Vault` it is given. NEVER run a built `clep` binary during development without `CLEPSYDRA__VAULT__ROOT=<scratch>` (the ambient config points at the live vault).
- `clep doctor` stays read-only: it never runs a git command that writes.
- Every public CLI command path needs a `## \`clep …\`` heading in `ui/src/docs/content/cli.mdx` (`tests/docs_cli_coverage_test.rs`); every API operation needs `### \`METHOD /api/vault/…\`` under a `## <Tag>` heading in `ui/src/docs/content/api-reference.mdx` (`tests/docs_api_coverage_test.rs`).

## Locked design decisions (this plan)

- **D1 Module split.** `src/vault/gitsync/` (git-backed sync) is distinct from the existing `src/vault/sync/` (filesystem watcher → index events). Server runtime in `src/sync_runtime.rs`; HTTP in `src/api/sync.rs`; CLI glue in `src/sync_command.rs`.
- **D2 Subprocess git.** `std::process::Command::new("git")` with `-C <root>`; the engine is synchronous; the server runs it under `tokio::task::spawn_blocking`. Every invocation sets `GIT_TERMINAL_PROMPT=0` and `LC_ALL=C`, and `GIT_SSH_COMMAND="ssh -o BatchMode=yes"` unless the process already has `GIT_SSH_COMMAND` set. Tests isolate git with `GIT_CONFIG_GLOBAL=<empty temp file>` and `GIT_CONFIG_NOSYSTEM=1` through `Git::with_env`.
- **D3 Initialised predicate.** A vault is sync-initialised iff `git rev-parse --show-toplevel` equals the vault root AND repo-local config `clep.sync.version` is set (written by `clep sync init`). Not initialised → the server has no `SyncRuntime` (with a startup `tracing::info!` when the root is a repo but not initialised), and `clep sync` / `clep sync status` fail with the hint `run clep sync init`.
- **D4 Merge mechanics.** `git merge --no-commit --no-edit origin/<branch>`. Outcomes: "Already up to date" (exit 0, no `MERGE_HEAD`, HEAD unchanged) → `UpToDate`; exit 0 + no `MERGE_HEAD` + HEAD moved → `FastForward`; exit 0 + `MERGE_HEAD` → clean merge to commit; exit 1 + unmerged paths → resolve (D6) then commit; any other failure → `git merge --abort` and error. The `*.md merge=clep` attribute is written now (Global Constraints); until phase 4b registers `merge.clep.driver`, git silently falls back to its text merge for that attribute (verified against git's `find_ll_merge_driver`), and D6 handles the residue.
- **D5 Conflict Copy shape.** Path: `<dir>/<stem>.conflict.<shortid>.md` where `shortid` = first 7 lowercase hex chars of `sha256(theirs bytes)` — deterministic (a re-run of the same merge is idempotent) and 7 characters so `is_canonical_page_filename` never matches (the copy is never mistaken for a dated journal file). Frontmatter when `theirs` parses: `id` = fresh `Uuid::now_v7()`, `title` = `"<original title> (conflict <shortid>)"` (a verbatim title would make every `[[Original Title]]` link ambiguous and unresolved), `conflict_of` = original vault-relative path, everything else (type, project, tags, aliases, timestamps, extras) copied from theirs. When `theirs` does not parse: raw bytes under the same copy name. Non-`.md` files: `<name>.conflict.<shortid><ext>` raw bytes.
- **D6 Resolution per unmerged path** (index stages 1=base, 2=ours, 3=theirs): stages {2,3} present → keep ours in the tree (`git checkout --ours -- <path>`), write theirs as a Conflict Copy unless ours == theirs byte-for-byte, `git add` both. Stage 2 only (deleted by them) → keep ours. Stage 3 only (deleted by us) → take theirs (`git checkout --theirs`). A page present in the tree is authoritative — the spec's "restore wins over purge" rule. Any other stage combination → warning, `checkout --ours` if stage 2 exists else `--theirs`.
- **D7 Push policy.** `git push -u origin <branch>`. A rejection ("rejected", "non-fast-forward", "fetch first" in stderr) triggers exactly one more fetch+merge+resolve+commit cycle and a second push; a second rejection is reported as `Rejected` — never `--force`.
- **D8 Per-device state.** `.git/clep-sync.toml` holds `last_sync_at` (RFC 3339) and `last_result` (one line). Inside `.git/`, so never synced and never needs ignoring.
- **D9 Author + device.** Commits use env `GIT_AUTHOR_NAME/EMAIL` + `GIT_COMMITTER_NAME/EMAIL` from `[sync]`. `clep sync init` seeds them from `git config --global user.name/user.email`, else from `--author-name`/`--author-email`, else prompts on a TTY, else errors. The `Device:` trailer value comes from `gethostname::gethostname()` (new dependency, `gethostname = "1"`).
- **D10 Quiesce.** `SyncRuntime::run_full_sync`: take `sync_lock` (one sync at a time) → `state.mutation_coordinator.exclude_mutations().await` (waits for in-flight mutations, blocks new ones) → set the watcher's `paused` flag (events are dropped while set) → `spawn_blocking(engine.full_sync)` → if the merge changed the tree (`FastForward` or `Merged`): `index.build` + `resolve_links` + `reconcile_all` + SSE `IndexChanged { upserted: ["*"] }` → clear `paused` → drop the exclusion. Autocommit holds the exclusion only (no pause, no rebuild: a commit never changes the tree).
- **D11 Cadence.** `SyncRuntime` subscribes to `state.change_tx`; every `IndexChanged`/`BaseRegistryChanged` marks dirty; after `autocommit_debounce_secs` of quiet it runs `commit_local`. When `interval_secs > 0` a second loop runs `run_full_sync` every interval. `run_server` runs one full sync after the state is built and before the reconcile sweep and watcher start (failures are logged, never fatal). SIGINT/SIGTERM trigger a graceful HTTP shutdown (`axum_server::Handle`, 5 s) followed by `commit_local` + `push` with a 30 s budget.
- **D12 LFS.** `init` with `LfsPolicy::Required`: `git lfs version` must succeed; then `git lfs install --local`; with `--remote`, probe the batch API: https(s) URLs → `POST <url without .git>.git/info/lfs/objects/batch` (`{"operation":"download","objects":[]}`) accepting any HTTP status except 404 and 5xx (401/403 mean "answers, needs auth"); scp/ssh URLs → `ssh -o BatchMode=yes <user@host> git-lfs-authenticate <path> download` must exit 0. The runtime never touches LFS directly (git's LFS hooks do).
- **D13 CLI/server split.** `clep sync` and `clep sync status` build `configured_api_client(cwd, false)` and `GET /api/vault/uptime`; success → the server does the work (`POST /api/vault/sync`, `GET /api/vault/sync/status`); `ApiCallError::Unreachable` → standalone engine on `open_vault()`; any other error is reported. `clep sync init` refuses while a server answers.
- **D14 Managed blocks.** `.gitignore` and `.gitattributes` get an idempotent block between `# >>> clep sync (managed) >>>` and `# <<< clep sync (managed) <<<`; lines already present anywhere in the file are not duplicated; existing user content is untouched.
- **D15 Config writer.** `[sync]` is written with `toml_edit::DocumentMut` into `.clepsydra/config.toml`, preserving every other line; only the keys being set are touched.
- **D16 CAS migration in init.** `init` runs `cas_migrate::migrate(vault, &legacy, true)` only when `cas_migrate::legacy_store_with_blobs()` is `Some` AND `cas::list_blob_hashes(&vault.cas_root())` is empty; otherwise the report says why it was skipped.

Out of scope here (phase 4b): `clep merge-driver` (structural frontmatter merge, `git merge-file` body merge, journal interleave), post-sync journal merger, doctor rules for Conflict Copies / duplicate journal dates, UI conflicts list, `Conflict-Copies` SSE variant.

/// `[sync]` — git-backed vault synchronisation (spec §4).
#[derive(Debug, Clone, Deserialize, PartialEq, Eq)]
pub struct SyncSection {
    /// Seconds of quiet after the last mutation before the server commits.
    #[serde(default = "default_autocommit_debounce_secs")]
    pub autocommit_debounce_secs: u64,
    /// Seconds between scheduled full syncs; `0` disables the schedule.
    #[serde(default)]
    pub interval_secs: u64,
    /// The single synced branch.
    #[serde(default = "default_sync_branch")]
    pub branch: String,
    #[serde(default)]
    pub author_name: Option<String>,
    #[serde(default)]
    pub author_email: Option<String>,
}

impl Default for SyncSection {
    fn default() -> Self {
        Self {
            autocommit_debounce_secs: default_autocommit_debounce_secs(),
            interval_secs: 0,
            branch: default_sync_branch(),
            author_name: None,
            author_email: None,
        }
    }
}

fn default_autocommit_debounce_secs() -> u64 {
    300
}

fn default_sync_branch() -> String {
    "main".to_string()
}
```

//!
//! Distinct from [`crate::vault::sync`], which turns filesystem events into
//! index updates. This module drives the system `git` binary: repository

    "*.md merge=clep",
    ".clepsydra/cas/** filter=lfs diff=lfs merge=lfs -text",
    "_attachments/** filter=lfs diff=lfs merge=lfs -text",

/// Commit identity taken from `[sync] author_name` / `author_email`.
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Author {
    pub name: String,
    pub email: String,
}

impl Author {
    /// The configured author, if both halves are present and non-blank.
    pub fn from_config(section: &crate::vault::config::SyncSection) -> Option<Self> {
        let name = section.author_name.as_deref()?.trim();
        let email = section.author_email.as_deref()?.trim();
        (!name.is_empty() && !email.is_empty()).then(|| Self {
            name: name.to_string(),
            email: email.to_string(),
        })
    }
}

#[derive(Debug, Error)]
pub enum SyncError {
    #[error("git is not installed or not on PATH: {0}")]
    GitMissing(String),
    #[error(transparent)]
    Git(#[from] git::GitError),
    #[error("vault root {root} is inside another git repository ({outer}); move the vault or remove the outer repository")]
    NestedRepo { root: String, outer: String },
    #[error("sync is not initialised for this vault — run `clep sync init`")]
    NotInitialised,
    #[error("[sync] author_name and author_email are not set — run `clep sync init`")]
    MissingAuthor,
    #[error("repository is on branch {actual:?} but [sync] branch = {configured:?}; check out the configured branch or change the config")]
    BranchMismatch { actual: String, configured: String },
    #[error("remote {name} already points at {existing}, not {requested}")]
    RemoteMismatch { name: String, existing: String, requested: String },
    #[error("git-lfs is required for sync but `git lfs version` failed: {0}. Install git-lfs (e.g. `brew install git-lfs`) and retry")]
    LfsMissing(String),
    #[error("remote {url} does not answer the git-lfs batch API ({detail}); sync requires an LFS-capable remote")]
    LfsRemoteUnsupported { url: String, detail: String },
    #[error("merge of {reference} failed: {detail}")]
    MergeFailed { reference: String, detail: String },
    #[error("I/O error at {path}: {source}")]
    Io { path: String, #[source] source: std::io::Error },
    #[error("{0}")]
    Config(String),
}

impl SyncError {
    pub(crate) fn io(path: &Path, source: std::io::Error) -> Self {
        Self::Io { path: path.display().to_string(), source }
    }
}

pub struct InitArgs { pub remote: Option<String>, pub author_name: Option<String>, pub author_email: Option<String> }

pub async fn run_init(args: InitArgs) -> Result<InitReport, Box<dyn std::error::Error>> {
    let cwd = std::env::current_dir()?;
    if reachable_server(&cwd).await?.is_some() {
        return Err("a clepsydra server is running on the configured address; stop `clep serve` before `clep sync init`".into());

        (None, None) => None,

impl SyncEngine {
    pub fn open_with_git(vault: &Vault, git: Git) -> Result<Self, SyncError> {
        if !super::is_initialised(vault, &git)? { return Err(SyncError::NotInitialised); }
        let author = Author::from_config(&vault.config().sync).ok_or(SyncError::MissingAuthor)?;
        Ok(Self { git, root: vault.root().to_path_buf(), branch: vault.config().sync.branch.clone(), author })
    }

    pub fn commit_local(&self) -> Result<Option<CommitSummary>, SyncError> {
        let entries = self.git.status()?;
        if entries.is_empty() { return Ok(None); }
        self.git.add_all()?;
        let message = commit_message(&self.root, &entries);
        let sha = self.git.commit(&message, &self.author)?;
        Ok(Some(CommitSummary { sha, files: entries.len(), message }))
    }

    pub fn pull(&self) -> Result<MergeSummary, SyncError> {
        if self.git.remote_url(REMOTE_NAME)?.is_none() { return Ok(MergeSummary::NoRemote); }
        if let Err(e) = self.git.fetch(REMOTE_NAME, &self.branch) { return Ok(MergeSummary::FetchFailed(e.to_string())); }
        let reference = format!("{REMOTE_NAME}/{}", self.branch);
        if self.git.rev_parse(&reference)?.is_none() { return Ok(MergeSummary::UpToDate); } // remote branch unborn
        let before = self.git.head()?;
        let out = self.git.merge_no_commit(&reference)?;
        let merge_head = self.git.merge_head()?;
        match (out.status, merge_head) {
            (0, None) => {
                let after = self.git.head()?;
                Ok(if after == before { MergeSummary::UpToDate } else { MergeSummary::FastForward { head: after.unwrap_or_default() } })
            }
            (0, Some(_)) => self.finish_merge(&reference, Vec::new()),
            (1, Some(_)) => {
                let copies = self.resolve_unmerged()?;
                self.finish_merge(&reference, copies)
            }
            (status, _) => {
                let _ = self.git.abort_merge();
                Err(SyncError::MergeFailed { reference, detail: format!("exit {status}: {}", out.stderr.trim()) })
            }
        }
    }

    fn resolve_unmerged(&self) -> Result<Vec<ConflictCopy>, SyncError> { /* D6 */ }

    fn finish_merge(&self, reference: &str, copies: Vec<ConflictCopy>) -> Result<MergeSummary, SyncError> {
        let mut message = format!("sync: merge {reference}");
        if !copies.is_empty() {
            message.push_str(&format!("\n\n{} conflict cop{}:\n", copies.len(), if copies.len() == 1 { "y" } else { "ies" }));
            for c in &copies { message.push_str(&format!("- {} -> {}\n", c.original, c.copy)); }
        }
        let commit = self.git.commit(&super::with_device_trailer(&message), &self.author)?;
        if let Err(e) = crate::vault::keyring::tighten_crypto_permissions(&self.root) { tracing::warn!("crypto permissions: {e}"); }
        Ok(MergeSummary::Merged { commit, conflict_copies: copies })
    }

    self.syncing.store(false, Ordering::SeqCst);
    result
}

async fn run_full_sync_inner(&self, state: &AppState) -> Result<SyncReport, SyncError> {
    let exclusion = state.mutation_coordinator.exclude_mutations().await;
    state.watcher_paused.store(true, Ordering::SeqCst);
    let engine = Arc::clone(&self.engine);
    let outcome = tokio::task::spawn_blocking(move || engine.full_sync()).await;
    let report = match outcome {
        Ok(Ok(report)) => report,
        Ok(Err(error)) => { state.watcher_paused.store(false, Ordering::SeqCst); drop(exclusion); return Err(error); }
        Err(join) => { state.watcher_paused.store(false, Ordering::SeqCst); drop(exclusion); return Err(SyncError::Config(format!("sync task panicked: {join}"))); }
    };
    if report.tree_changed() {
        rebuild_after_sync(state).await;   // index.build + resolve_links + reconcile_all + warnings + SSE "*"
    }
    self.pending.store(false, Ordering::SeqCst);
    state.watcher_paused.store(false, Ordering::SeqCst);
    drop(exclusion);
    *self.last.lock() = Some(report.clone());
    Ok(report)
}
```
