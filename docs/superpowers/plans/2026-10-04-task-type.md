# Task Type — TDD plan (2026-10-04)

Branch `feature/task-type`, worktree `.worktrees/task-type`.

## Rulings (user, 2026-10-04)

- New optional, clearable Task Field: **task type**. Frontmatter key `task_type`.
- Closed vocabulary: `FEATURE`, `FIX`, `TASK`, `STORY`, `SPIKE`.
- Optional. Untyped tasks show no badge. No migration of existing tasks.
- Display: small mono text chip next to the priority chip.
- v1 surfaces: TaskCard + BacklogView + CycleView rows badge; TaskEditPanel + NewTaskModal picker (with a "None" choice); FilterBar "Type" facet (with "Untyped"); MCP `vault_task_create` / `vault_task_update` params.
- Not in v1: TimelineView, QuickAddRow syntax, checkbox (block) tasks.

## Implementer choices

- Wire/DTO field name is `task_type` everywhere (JSON, MCP params), matching the frontmatter key.
- Input is case-insensitive; stored uppercase. Unknown value → 400 listing valid values.
- Read side passes a hand-edited unknown frontmatter value through unchanged (no silent drop).
- Clear semantics follow the other tri-state fields: absent keeps, `null`/`""`/whitespace clears.

## Task 1 — backend (Rust)

Files: `crates/clep-vault/src/board_vocab.rs` (or `crates/clep-api/src/api/board/mod.rs` next to `PRIORITIES`), `board/mod.rs` (DTOs), `board/read.rs`, `board/task_patch.rs`, `crates/clep-mcp/src/server.rs`, `crates/clep-api/tests/api_board_test.rs`.

Tests first (red), then code:

1. `task_patch.rs` unit tests:
   - `from_tri_state` mapping for `task_type` on PATCH (absent/null/""/value).
   - create with `task_type: "fix"` → meta extra `task_type = "FIX"`.
   - patch with unknown `task_type` → `TaskPatchError::UnknownTaskType`, meta untouched.
   - patch clear removes the key.
2. `api_board_test.rs` integration:
   - POST `/tasks` with `task_type` → GET board returns `task_type: "FIX"` on that task.
   - PATCH `task_type: null` clears; PATCH `"BOGUS"` → 400 whose message lists the 5 values.
   - Task without the key → `task_type: null`.
3. MCP `server.rs` tests: `vault_task_create` passes `task_type`; `vault_task_update` tri-state like `estimate` (add to the `for field in [...]` loop test).

Implementation:
- `TASK_TYPES: &[&str] = &["FEATURE", "FIX", "TASK", "STORY", "SPIKE"]` beside `PRIORITIES`.
- `BoardTask.task_type: Option<String>`; `CreateTaskRequest.task_type: Option<String>`; `PatchTaskRequest.task_type` tri-state with docs.
- `TaskPatch.task_type: FieldChange`; validate + uppercase in `apply_task_patch` before any mutation; `apply_field(meta, "task_type", ...)`.
- `read.rs`: `extra_str(&meta, "task_type")` at both task construction sites.
- MCP: params + tool descriptions mention `task_type` and the vocabulary.
- Regenerate schema: `cargo run -q -p clep-api --example openapi > target/openapi.json && (cd ui && bun run openapi:file)`.
- Docs: `CONTEXT.md` Task Fields list gains "task type"; `ui/src/docs/content/mcp.mdx` and `tasks-agenda-journals-and-board.mdx` mention it.

Gates: `cargo fmt`, `cargo clippy --all-targets -- -D warnings` (as the repo runs it), `cargo test -p clep-api -p clep-mcp`.

## Task 2 — frontend (after Task 1; needs `schema.d.ts`)

Files: `ui/src/components/tasking/board-constants.tsx`, `fields.tsx`, `board-presentation.tsx`, `TaskCard.tsx`, `BacklogView.tsx`, `CycleView.tsx`, `TaskEditPanel.tsx`, `NewTaskModal.tsx`, `TaskingScreen.tsx`, `QuickAddRow.tsx` (send `task_type: null` if the create body type requires it), `ui/src/api/board.ts` if it maps fields; tests under `__tests__/`.

Tests first:
- `TypeChip` renders the type text; renders nothing for null.
- TaskCard shows `FIX` chip for a typed task, none for untyped.
- `TypeRow` picker: 6 choices (None + 5); selecting calls onChange with value / null.
- TaskEditPanel: choosing a type PATCHes `{ task_type: "FIX" }`; choosing None PATCHes `{ task_type: null }`.
- NewTaskModal: chosen type lands in the create body; default None sends nothing/null.
- `BOARD_FILTER_CONFIG` type accessor: typed → `[type]`, untyped → `["UNTYPED"]`; facet options = 5 types + Untyped.

Implementation:
- `board-constants.tsx`: `TYPE_ORDER`, `TYPE_LABEL` (Feature, Fix, Task, Story, Spike), `TYPE_NONE = "UNTYPED"`.
- `TypeChip` in `board-presentation.tsx` beside `PriChip`: mono, small, `--mute` tone; `FIX` uses `--hot`. Stone & Lamp tokens only.
- `TypeRow` in `fields.tsx` modelled on `PriorityRow` (segmented RadioGroup, no dots).
- Badge after the priority chip in TaskCard / BacklogView / CycleView rows.
- FilterBar facet `{ id: "type", kind: "multi", label: "Type" }`.

Gates (from `ui/`): `bun run typecheck`, `bun run lint`, `bun run test`.
