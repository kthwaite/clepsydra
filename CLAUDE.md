# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Clepsydra is a personal knowledge management system ("digital garden") with a Rust backend and React frontend. The vision includes a Notion-style document editor, markdown-oxide style LSP for Neovim, and features inspired by Obsidian, Quartz, and Neorg.

## Build & Development Commands

### Frontend (ui/)

All frontend commands run from the `ui/` directory using Bun:

```bash
cd ui
bun install              # Install dependencies
bun run dev              # Start Vite dev server
bun run build            # Typecheck + production build
bun run typecheck        # TypeScript type checking only
bun run lint             # Lint with Biome
bun run format           # Format + lint auto-fix (runs `biome check --fix`)
bun run storybook        # Storybook dev server on port 6006
bun run build-storybook  # Build static Storybook
```

### Backend (Rust)

```bash
cargo build              # Build debug
cargo run -- serve       # Run API server (requires subcommand)
cargo test               # Run all tests
cargo test <name>        # Run single test by name
cargo clippy             # Lint
cargo fmt                # Format
```

The CLI binary (`clepsydra`) uses subcommands: `serve`, `init`, `env`, `doctor`, `version`. Only `serve` is implemented so far.

## Architecture

### Frontend Stack (ui/)

- **React 19** with TanStack Router (file-based routing) and TanStack Query (data fetching)
- **Rolldown-Vite** — Vite is overridden to `rolldown-vite` via package.json `overrides`. Do not add a separate `vite` dependency.
- **Tailwind CSS v4** — All design tokens live in `ui/src/main.css` via `@theme` blocks. No `tailwind.config` file.
- **Biome** for linting and formatting (replaces ESLint/Prettier). Config in `ui/biome.json`.
- **react-aria-components** for accessible UI primitives
- **Storybook 10** for component development (`ui/.storybook/`)

**Path alias:** `#/` maps to `ui/src/` (configured in both `tsconfig.app.json` and `vite.config.ts`). Use `import { Foo } from "#/components/Foo"` not relative paths.

**Auto-generated files (do not edit):**
- `ui/src/routeTree.gen.ts` — Generated by TanStack Router plugin

### Backend Stack (src/)

- **Rust 2024 edition** with Axum web framework, Clap CLI, and Tokio async runtime
- **Configuration layering:** defaults → `config.toml` → env vars (`CLEPSYDRA__SERVER__HOST`, `CLEPSYDRA__SERVER__PORT`)
- Entry point: `src/bin/cli.rs` (CLI dispatch) → `src/lib.rs` (server logic)

### Design Aesthetic

The UI follows a **brutalist / high modernist** visual language:
- Zero border-radius (`--radius: 0`) — no rounded corners anywhere
- Hard-edged offset shadows (bottom-right, no blur)
- Achromatic palette (oklch, zero chroma) with high contrast
- Light/dark mode via `.dark` class on `<html>`, toggled by `ThemeProvider`

All semantic color tokens (background, foreground, primary, muted, border, etc.) are defined in `ui/src/main.css`. Respect these tokens when building UI.

## Code Style

### TypeScript/React
- Biome handles formatting (2-space indent, double quotes, organized imports)
- Strict TypeScript (`noUnusedLocals`, `noUnusedParameters`, `verbatimModuleSyntax`)
- Use `clsx` and `tailwind-merge` for conditional class composition

### Rust
- Standard `rustfmt` and `clippy` conventions

## Git Workflow

- `main` is the primary branch; `develop` is the integration branch
